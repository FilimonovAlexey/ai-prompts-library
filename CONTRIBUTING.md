# Руководство по внесению вклада

Спасибо за интерес к проекту! Мы рады любому вкладу в библиотеку промтов.

## Структура репозитория

```
ai-prompts-library/
├── prompts/
│   ├── text/           # Промты для работы с текстом
│   ├── code/           # Промты для генерации и работы с кодом
│   ├── images/         # Промты для генерации изображений
│   └── video/          # Промты для работы с видео
│       ├── chatgpt/
│       ├── claude/
│       ├── gemini/
│       ├── midjourney/
│       ├── stable-diffusion/
│       └── other/
├── PROMPT_TEMPLATE.md  # Шаблон для создания промтов
└── README.md
```

## Как добавить новый промт

1. Выберите категорию задачи (`text`, `code`, `images`, `video`)
2. Выберите подходящую модель (`chatgpt`, `claude`, `gemini`, `midjourney`, `stable-diffusion`, `other`)
3. Создайте новый файл в соответствующей директории
4. Используйте `PROMPT_TEMPLATE.md` как основу
5. Заполните YAML front matter метаданными
6. Напишите подробное описание и пример использования

## Формат файла промта

Каждый промт должен быть в формате Markdown с YAML front matter:

```markdown
---
title: "Название промта"
description: "Краткое описание"
category: "text"
model: "chatgpt"
tags:
  - "тег1"
  - "тег2"
author: "Ваше имя"
version: "1.0"
language: "ru"
difficulty: "beginner"
created: "2024-01-01"
updated: "2024-01-01"
---

# Название промта
...
```

## Обязательные поля в YAML front matter

- `title` - название промта
- `description` - краткое описание (1-2 предложения)
- `category` - категория задачи: `text`, `code`, `images`, `video`
- `model` - модель: `chatgpt`, `claude`, `gemini`, `midjourney`, `stable-diffusion`, `other`
- `tags` - список тегов для поиска
- `author` - имя автора
- `version` - версия промта (используйте семантическое версионирование)
- `language` - язык промта (`ru`, `en`, и т.д.)
- `difficulty` - сложность: `beginner`, `intermediate`, `advanced`
- `created` - дата создания (YYYY-MM-DD)
- `updated` - дата последнего обновления (YYYY-MM-DD)

## Требования к качеству

1. **Ясность**: промт должен быть понятным и легко адаптируемым
2. **Примеры**: всегда включайте примеры использования
3. **Документация**: подробно описывайте назначение и особенности
4. **Тестирование**: убедитесь, что промт работает на указанной модели

## Именование файлов

- Используйте snake_case для имен файлов
- Имя должно быть описательным
- Примеры: `code_review_assistant.md`, `image_generation_detailed.md`

## Процесс добавления

1. Форкните репозиторий
2. Создайте новую ветку (`git checkout -b feature/new-prompt`)
3. Добавьте свой промт в соответствующую директорию
4. Закоммитьте изменения (`git commit -am 'Add new prompt: название'`)
5. Запушьте ветку (`git push origin feature/new-prompt`)
6. Создайте Pull Request

## Обновление существующих промтов

При обновлении существующего промта:
1. Увеличьте версию в YAML front matter
2. Обновите поле `updated`
3. Опишите изменения в commit message
