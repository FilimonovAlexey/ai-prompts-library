# Промты для работы с текстом

Промты для генерации, редактирования и анализа текстового контента.

## Категории по моделям

- [ChatGPT](chatgpt/) - промты для ChatGPT (GPT-3.5, GPT-4)
- [Claude](claude/) - промты для Claude (Claude 2, Claude 3)
- [Gemini](gemini/) - промты для Gemini (Gemini Pro, Ultra)
- [Other](other/) - промты для других моделей

## Типы текстовых промтов

- **Контент-создание**: статьи, посты, описания продуктов
- **Редактирование**: улучшение текста, корректура, стилистика
- **Перевод**: перевод с сохранением контекста и стиля
- **Анализ**: анализ тональности, извлечение ключевых идей
- **Резюмирование**: краткие выжимки из длинных текстов
- **Креативное письмо**: истории, сценарии, поэзия

## Как выбрать модель

- **ChatGPT**: универсальная модель для большинства задач, хорошо работает с русским языком
- **Claude**: отлично подходит для анализа и работы с длинными текстами
- **Gemini**: хорошо справляется с многоязычными задачами и сложными контекстами
