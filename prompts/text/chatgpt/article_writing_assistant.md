# Помощник по написанию статей

## Описание
Этот промт помогает создавать качественные, структурированные статьи на любую тему. Промт генерирует план статьи, а затем создает полный текст с введением, основной частью и заключением.

## Промт
```
Ты — опытный копирайтер и журналист. Помоги мне написать статью на тему: [ТЕМА].

Требования:
1. Создай структурированный план статьи с заголовками и подзаголовками
2. Напиши статью объемом примерно [КОЛИЧЕСТВО] слов
3. Используй понятный язык для целевой аудитории: [АУДИТОРИЯ]
4. Включи введение, основную часть и заключение
5. Добавь факты и примеры для иллюстрации основных идей
6. Используй стиль: [СТИЛЬ] (например, информативный, разговорный, академический)

Начни с создания плана статьи, затем напиши полный текст.
```

## Пример использования

### Входные данные
```
Тема: "Преимущества утренней зарядки"
Количество слов: 800
Аудитория: Офисные работники
Стиль: Информативный и мотивирующий
```

### Ожидаемый результат
ChatGPT создаст:
1. Структурированный план статьи с разделами
2. Полную статью с введением, основной частью и заключением
3. Факты и примеры о пользе утренней зарядки
4. Практические советы для читателей

## Советы по использованию
- Будьте конкретны в описании темы и целевой аудитории
- Укажите желаемый объем текста для более точного результата
- Можете попросить добавить конкретные разделы или аспекты
- После первого результата можете попросить расширить или сократить определенные части

## Примечания
- Промт можно адаптировать для статей в блог, новостных материалов, образовательного контента
- Рекомендуется проверить факты, особенно для специализированных тем
- Можно использовать с GPT-3.5, GPT-4, или GPT-4 Turbo
