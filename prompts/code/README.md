# Промты для работы с кодом

Промты для генерации кода, рефакторинга, отладки и документирования.

## Категории по моделям

- [ChatGPT](chatgpt/) - промты для ChatGPT (GPT-3.5, GPT-4)
- [Claude](claude/) - промты для Claude (Claude 2, Claude 3)
- [Gemini](gemini/) - промты для Gemini (Gemini Pro, Ultra)
- [Other](other/) - промты для других моделей

## Типы промтов для кода

- **Генерация кода**: создание функций, классов, компонентов
- **Рефакторинг**: улучшение существующего кода
- **Код-ревью**: анализ качества и best practices
- **Отладка**: поиск и исправление ошибок
- **Тестирование**: создание unit-тестов, integration-тестов
- **Документация**: комментарии, README, API docs
- **Оптимизация**: улучшение производительности

## Поддерживаемые языки программирования

Python, JavaScript, TypeScript, Java, C++, C#, Go, Rust, PHP, Ruby, Swift, Kotlin и другие.

## Как выбрать модель

- **ChatGPT**: универсальная модель, хорошо работает с популярными языками
- **Claude**: отлично подходит для код-ревью и анализа сложного кода
- **Gemini**: хорошо справляется с многофайловыми проектами и рефакторингом
