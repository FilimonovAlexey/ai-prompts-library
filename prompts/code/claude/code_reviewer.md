# Ревьюер кода

## Описание
Этот промт помогает провести детальное ревью кода с фокусом на читаемость, производительность, безопасность и следование best practices. Claude проанализирует код и даст конструктивные рекомендации.

## Промт
```
Ты — опытный senior-разработчик и код-ревьюер. Проведи детальное ревью следующего кода.

Проанализируй код по следующим критериям:

1. **Читаемость и чистота кода**
   - Понятность именования переменных и функций
   - Структура и организация кода
   - Комментарии (где нужны)

2. **Производительность**
   - Эффективность алгоритмов
   - Потенциальные узкие места
   - Оптимизация ресурсов

3. **Безопасность**
   - Уязвимости безопасности
   - Валидация входных данных
   - Обработка ошибок

4. **Best Practices**
   - Соответствие стандартам языка
   - Паттерны проектирования
   - SOLID принципы

5. **Тестируемость**
   - Возможность написания тестов
   - Зависимости и связанность

Для каждого найденного замечания:
- Опиши проблему
- Объясни, почему это важно
- Предложи конкретное решение с примером кода

Код для ревью:
[ВСТАВЬ КОД ЗДЕСЬ]

Язык программирования: [ЯЗЫК]
```

## Пример использования

### Входные данные
```python
def calc(a, b, op):
    if op == '+':
        return a + b
    elif op == '-':
        return a - b
    elif op == '*':
        return a * b
    elif op == '/':
        return a / b
```

### Ожидаемый результат
Claude проанализирует код и укажет на:
- Отсутствие обработки деления на ноль
- Неясное имя функции
- Отсутствие документации
- Возможность использования словаря операторов
- Предложит улучшенный вариант с примером

## Советы по использованию
- Предоставляйте контекст: назначение кода, требования, ограничения
- Укажите, на что обратить особое внимание
- Можете запросить ревью только определенных аспектов
- Для больших файлов лучше разбить на логические части

## Примечания
- Claude особенно хорош в анализе кода и предоставлении подробных объяснений
- Рекомендуется для кода на Python, JavaScript, TypeScript, Java, C++, Rust
- Промт можно адаптировать для специфичных фреймворков или библиотек
