# Промты для генерации изображений

Промты для создания изображений с помощью AI: арт, дизайн, фотореализм, иллюстрации.

## Категории по моделям

- [Midjourney](midjourney/) - промты для Midjourney (v5, v6)
- [Stable Diffusion](stable-diffusion/) - промты для SD, SDXL, Flux
- [Other](other/) - промты для DALL-E, Imagen и других моделей

## Типы промтов для изображений

- **Фотореализм**: реалистичные фото, портреты, пейзажи
- **Арт и иллюстрации**: концепт-арт, цифровая живопись, векторные иллюстрации
- **Дизайн**: UI/UX, логотипы, брендинг
- **3D и рендеры**: 3D-визуализация, архитектура
- **Стилизация**: аниме, комиксы, стиль конкретных художников
- **Продуктовая фотография**: товары, еда, предметы

## Особенности моделей

### Midjourney
- Сильные стороны: художественный стиль, композиция, эстетика
- Лучше для: концепт-арт, иллюстрации, креативные работы
- Использует Discord интерфейс

### Stable Diffusion / Flux
- Сильные стороны: контроль, кастомизация, open-source
- Лучше для: специфичные задачи, дообучение, batch-генерация
- Можно запускать локально

### DALL-E (Other)
- Сильные стороны: понимание текста, безопасность
- Лучше для: простые задачи, интеграция с ChatGPT
- Встроен в ChatGPT Plus

## Ключевые элементы промта

1. **Основной объект**: что изображено
2. **Стиль**: фотореализм, арт, конкретный художник
3. **Освещение**: студийное, естественное, драматичное
4. **Композиция**: ракурс, кадрирование
5. **Детали**: цвета, текстуры, атмосфера
6. **Технические параметры**: разрешение, качество, AR
