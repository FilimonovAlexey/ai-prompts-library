# Промты для работы с видео

Промты для анализа видео, создания сценариев и описаний для video-генерации.

## Категории по моделям

- [ChatGPT](chatgpt/) - промты для работы с видео в ChatGPT
- [Claude](claude/) - промты для анализа и сценариев в Claude
- [Gemini](gemini/) - промты для мультимодального анализа видео
- [Other](other/) - промты для других моделей (Sora, Runway и т.д.)

## Типы промтов для видео

- **Анализ видео**: описание содержания, транскрипты, резюме
- **Сценарии**: написание сценариев для видео
- **Storyboards**: создание раскадровки
- **Промты для генерации**: описания для AI video generation (Sora, Runway)
- **Редактирование**: советы по монтажу, тайминг
- **Субтитры**: создание и перевод субтитров

## Мультимодальные возможности

### Gemini
- Может анализировать загруженное видео
- Создает детальные описания содержания
- Извлекает текст и аудио
- Поддержка длинных видео

### ChatGPT (с GPT-4V)
- Анализ кадров из видео
- Создание описаний сцен
- Рекомендации по улучшению

## Генерация видео

Для моделей генерации видео (Sora, Runway, Pika):
- Детальные описания сцен
- Стиль и атмосфера
- Движение камеры
- Освещение и цвета
- Длительность и темп

## Примеры задач

- Создание резюме длинных видео
- Извлечение ключевых моментов
- Написание видео-сценариев
- Создание промтов для AI video generation
- Анализ образовательного контента
- Транскрипция речи
