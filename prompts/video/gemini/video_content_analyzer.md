# Анализатор видео контента

## Описание
Этот промт использует мультимодальные возможности Gemini для анализа видео контента. Gemini может просматривать видео и предоставлять детальное описание, резюме и анализ содержимого.

## Промт
```
Проанализируй это видео и предоставь следующую информацию:

1. **Общее резюме** (2-3 предложения)
   - Основная тема видео
   - Ключевое сообщение

2. **Детальный анализ**
   - Структура видео (основные сегменты)
   - Ключевые моменты и темы
   - Визуальный стиль и техники

3. **Контент по временным меткам**
   - Важные моменты с указанием времени
   - Краткое описание каждого сегмента

4. **Технические аспекты**
   - Качество видео и звука
   - Монтаж и переходы
   - Использованные эффекты

5. **Целевая аудитория и применение**
   - Для кого предназначено видео
   - Возможные сценарии использования

Фокус анализа: [УКАЖИТЕ КОНКРЕТНЫЙ АСПЕКТ, если нужно]
```

## Пример использования

### Входные данные
- Загрузите видео в Gemini
- Укажите фокус анализа: "Обучающий контент, техники презентации"

### Ожидаемый результат
Gemini предоставит:
1. Краткое резюме содержания видео
2. Детальный анализ структуры и контента
3. Временные метки ключевых моментов
4. Оценку технического качества
5. Рекомендации по целевой аудитории

## Советы по использованию
- **Качество видео**: загружайте видео в хорошем качестве для лучшего анализа
- **Длительность**: Gemini хорошо справляется с видео до 60 минут
- **Специфичные запросы**: укажите конкретные аспекты, на которые нужно обратить внимание
- **Язык видео**: Gemini может анализировать видео на разных языках

### Дополнительные варианты анализа:
- Создание транскрипта речи из видео
- Извлечение ключевых цитат
- Анализ эмоций и тональности
- Сравнение нескольких видео

### Типы видео для анализа:
- Обучающие видео и курсы
- Презентации и выступления
- Маркетинговые ролики
- Новостной контент
- Влоги и интервью

## Примечания
- Gemini Pro Vision имеет мультимодальные возможности для работы с видео
- Для длинных видео может потребоваться больше времени на обработку
- Промт можно адаптировать для создания субтитров или транскриптов
- Полезно для контент-мейкеров, маркетологов, исследователей
