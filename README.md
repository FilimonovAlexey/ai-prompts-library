## 🎯 О проекте

Этот репозиторий создан для удобного хранения, поиска и обмена промтами для различных нейросетей. Все промты оформлены в едином формате (Markdown + YAML front matter) и организованы по категориям задач и моделям.

### Цели проекта:
- ✅ Удобное хранение и поиск промтов
- ✅ Единый формат оформления
- ✅ Категоризация по задачам и моделям
- ✅ Open-source сообщество

## 🏷️ Категории промтов

### 📝 Text (Текст)
Промты для работы с текстом: написание статей, редактирование, перевод, анализ тональности, создание резюме и т.д.

### 💻 Code (Код)
Промты для генерации кода, рефакторинга, написания тестов, код-ревью, отладки и документирования.

### 🖼️ Images (Изображения)
Промты для генерации изображений: арт, дизайн, иллюстрации, фотореализм, стилизация и т.д.

### 🎬 Video (Видео)
Промты для работы с видео: описания для генерации, сценарии, анализ видео и т.д.

## 🤖 Поддерживаемые модели

- **ChatGPT** (GPT-3.5, GPT-4, GPT-4 Turbo)
- **Claude** (Claude 2, Claude 3)
- **Gemini** (Gemini Pro, Gemini Ultra)
- **Midjourney** (для генерации изображений)
- **Stable Diffusion / Flux** (для генерации изображений)
- **Other** (другие модели)

## 🚀 Как использовать

1. **Найдите нужный промт**: перейдите в соответствующую категорию и модель
2. **Откройте файл промта**: прочитайте описание и примеры использования
3. **Скопируйте промт**: используйте промт с выбранной нейросетью
4. **Адаптируйте под свои нужды**: измените промт для вашей конкретной задачи

### Пример структуры промта

Каждый промт содержит:
- YAML front matter с метаданными (название, категория, модель, теги, автор, версия)
- Подробное описание
- Текст промта
- Примеры использования
- Советы по применению
